
# Teach Me — из конспекта в учебные карточки

Teach Me — учебное Django-приложение, которое превращает текстовый конспект в вопросы, ответы и цитаты из исходного текста. Карточки сохраняются в базе данных и доступны по постоянной ссылке.

## Возможности

- Ввод названия и текста конспекта.
- Генерация учебных карточек в режиме DEMO или LIVE.
- Сохранение конспекта и карточек в SQLite.
- Отдельная страница сохранённого конспекта.
- Раскрытие и сворачивание ответов и цитат.
- Проверка введённых данных и результата генерации.
- Сохранение нескольких карточек с порядковыми номерами.

В режиме DEMO используется заранее подготовленный конспект о компьютерных сетях и три карточки. Этот режим позволяет проверять приложение без API-ключа и обращения к внешнему сервису.

## Требования

- Python 3.10 или новее рекомендуется.
- Django `>=5.2,<5.3`.
- python-dotenv `>=1.1,<2`.

## Установка на Windows

Открой PowerShell и перейди в каталог проекта, где находится `manage.py`.

Создай виртуальное окружение:

```powershell
python -m venv .venv
```

Активируй его:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установи зависимости:

```powershell
python -m pip install -r requirements.txt
```

Если PowerShell запрещает активацию окружения, используй Python из виртуального окружения напрямую:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Установка на macOS и Linux

Перейди в каталог проекта, где находится `manage.py`.

Создай и активируй виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установи зависимости:

```bash
python -m pip install -r requirements.txt
```

## Настройка окружения

В каталоге с `manage.py` создай файл `.env`, используя `.env.example` как шаблон.

Пример содержимого:

```dotenv
TEACHME_MODE=demo
GEMINI_API_KEY=
GEMINI_MODEL=
GEMINI_TIMEOUT_SECONDS=25
```

### Режим DEMO

```dotenv
TEACHME_MODE=demo
```

DEMO не требует API-ключа. Для демонстрации используй подготовленный пример конспекта о компьютерных сетях. Другой текст может быть отклонён DEMO-провайдером.

### Режим LIVE

Для использования Gemini API укажи параметры:

```dotenv
TEACHME_MODE=live
GEMINI_API_KEY=your_api_key
GEMINI_MODEL=your_model_name
GEMINI_TIMEOUT_SECONDS=25
```

Замени `your_api_key` и `your_model_name` действительными значениями, поддерживаемыми используемой конфигурацией Gemini.

API-ключ должен храниться только в локальном `.env`. Не публикуй его в GitHub, исходном коде или скриншотах. Файл `.env` не следует добавлять в Git.

Доступность LIVE зависит от правильности ключа, имени модели, сетевого соединения и доступности API. Успешный запуск DEMO не подтверждает работоспособность LIVE.

## Запуск базы данных

Выполни миграции:

```bash
python manage.py migrate
```

## Запуск приложения

Запусти локальный сервер:

```bash
python manage.py runserver 127.0.0.1:8000
```

Открой главную страницу:

http://127.0.0.1:8000/

После сохранения конспекта приложение перенаправляет на страницу с постоянным URL вида:

```text
http://127.0.0.1:8000/sources/<pk>/
```

Вместо `<pk>` будет идентификатор сохранённого конспекта.

Повторное открытие страницы или обновление браузера методом F5 должно загружать сохранённые данные из базы. Для проверки перезапусти сервер и снова открой прежний URL.

## Проверка проекта

Запусти команды из каталога с `manage.py`:

```bash
python manage.py check
```

Проверка тестов:

```bash
python manage.py test study
```

Проверка отсутствия новых изменений в моделях, требующих миграций:

```bash
python manage.py makemigrations --check --dry-run
```

На Windows вместо `python` можно использовать:

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py test study
.\.venv\Scripts\python.exe manage.py makemigrations --check --dry-run
```

Результаты этих команд необходимо записывать по фактическому выводу терминала. Ожидаемый результат не является подтверждением успешного выполнения.

## Структура приложения

Основные файлы приложения `study`:

- `study/models.py` — модели сохранённого конспекта и учебных карточек.
- `study/forms.py` — форма ввода и базовая проверка конспекта.
- `study/services.py` — генерация карточек и проверка результата.
- `study/views.py` — обработка запросов, сохранение и просмотр данных.
- `study/urls.py` — маршруты главной страницы и сохранённых конспектов.
- `study/templates/study/home.html` — форма ввода и список сохранённых конспектов.
- `study/templates/study/source_detail.html` — страница конспекта и карточек.
- `study/tests.py` — автоматические тесты.

## Ограничения

- DEMO поддерживает заранее заданный демонстрационный текст, а не произвольную генерацию.
- Проверка цитаты подтверждает, что цитата присутствует в исходном тексте. Она не доказывает истинность ответа или достоверность самого конспекта.
- Качество карточек, созданных в LIVE, зависит от модели и исходного материала.
- В текущей версии нет полноценной авторизации и разграничения данных по владельцам. Не используй приложение для хранения конфиденциальных конспектов в публично доступной среде.
- Локальный сервер предназначен для разработки и демонстрации, а не для промышленного развёртывания.
